## Directory guide

| Folder | Purpose |
| --- | --- |
| [`Docs`](Docs/) | Lecture documents, course handouts, and book or reference material for the semester subjects. |
| [`Assignment`](Assignment/) | Assignment notebooks, requirements, explanations, and related submission work. |
| [`practice`](practice/) | Practice exercises and additional learning work. |

## Recommended workflow

1. Start with the relevant lecture documents or books in [`Docs`](Docs/).
2. Use [`practice`](practice/) to work through exercises.
3. Complete and run notebooks in [`Assignment`](Assignment/).
4. Follow the assignment-specific setup instructions in [`Assignment/README.md`](Assignment/README.md).

The root-level `venv/` directory contains the current Python virtual environment. Assignment setup instructions use a separate `Assignment/.venv/` environment so that assignment dependencies remain isolated.
